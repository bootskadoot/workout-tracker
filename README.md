## Workout Progress Tracker

A minimal, mobile-friendly workout logging app built with **React + Vite** using **localStorage** for persistence.

- **Exercise library**: Managed through a JSON editor and simple add button under the Exercises tab.
- **Log workouts**: Quick form with date, exercise, sets, reps, and weight/duration.
- **History**: Most recent workouts listed first.

### Running locally

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production (Netlify, etc.): `npm run build`

The app is a standard Vite SPA and can be deployed on Netlify by pointing a site at the repo and using:

- **Build command**: `npm run build`
- **Publish directory**: `dist`
